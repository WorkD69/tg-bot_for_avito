# Daily Launch Ops Checklist

Жёсткий рабочий чеклист на период запуска (первые 30 дней).
Утром — 5 минут. Вечером — 3 минуты. Без воды.

---

## Утро (5 минут)

```
/stats
/sourcestats today
```

- [ ] Сколько новых регистраций вчера? (норма при активной рекламе: ≥2/день)
- [ ] Есть ли заявки в статусе `awaiting_payment` дольше 24 часов? → напомнить клиенту
- [ ] `⏳ К выплате операторам` больше 5000 ₽? → запланировать выплату
- [ ] `🔒 Заморожено` больше 0? → проверить спор, решить
- [ ] Споров (`⚖️`) больше 1 за неделю? → поговорить с оператором

---

## Вечер (3 минуты)

```
/stats
```

- [ ] Все заявки в работе двигаются? (нет завязших в `in_progress` > 48h)
- [ ] Есть операторы онлайн на завтра? (если нет ставок — написать оператору)
- [ ] Follow-up counter растёт? (`📬 Follow-up отправлено: N`) — значит заявки завершаются

---

## Раз в 3 дня (в первые 2 недели)

```
/sourcestats 7d
/campaignstats avito 7d
```

- [ ] Есть ли трафик с нужных источников?
- [ ] Какое объявление даёт больше регистраций?
- [ ] Обновить `day3_result` в CAMPAIGN_TRACKER_TEMPLATE.md

## Раз в неделю

```
/sourcefunnel 7d
/campaignstats 7d
/operatorstats

```

- [ ] Completion rate по каждому источнику выше 20%?
- [ ] Кто из операторов завершил больше заявок?
- [ ] Есть ли операторы с pending выплатами → выплатить через `/markpaid`
- [ ] Обновить `day7_result` и `decision` в трекере

## Красные флаги и что делать

### Регистрации есть, заявок нет

**Симптом:** `/sourcestats` показывает новых пользователей, `/sourcefunnel` показывает 0 заявок

**Причины и действия:**
1. Welcome-сообщение непонятное → проверь текст welcome для источника в коде
2. Кнопка «Создать заявку» не нажимается → тестовый прогон от руки
3. Трафик нецелевой (школьники без денег / боты) → поменять текст объявления, добавить цену

---

### Заявки есть, оплат нет

**Симптом:** orders_created > 0, orders_paid = 0 в `/sourcefunnel`

**Причины и действия:**
1. Цена слишком высокая → проверь через `/campaignstats` где именно теряешь
2. Клиент не понимает как платить → проверить платёжный flow вручную
3. Ставки операторов не приходят → проверить что операторы активны (`/operators`)
4. Автораспределение не срабатывает → проверить что есть заявки в `pending` (`/stats`)

---

### Оплаты есть, завершений мало

**Симптом:** orders_paid > 0, completion rate < 50%

**Причины и действия:**
1. Операторы медленно работают → `/operatorstats` — кто тормозит
2. Клиент не доволен качеством → смотреть отзывы (`/reviews` если есть)
3. Спор открыт → `/stats` → `⚖️ Споров` → разрулить через `/disputes`

---

### Споры (disputes)

**Симптом:** `⚖️ Споров: N` в `/stats`, N > 0

**Действия:**
1. Уточнить у оператора и клиента в чём проблема
2. Если вина оператора → `/freezeearning` (заморозить выплату), потребовать переделку
3. Если вина клиента (необоснованная претензия) → `/unfreezeearning`, объяснить клиенту
4. Долгий спор → `/cancelorder` с возвратом по договорённости

---

### Рост pending выплат операторам

**Симптом:** `⏳ К выплате операторам` > 10 000 ₽ в `/stats`

**Действия:**
1. `/payouts` — кому и сколько
2. Перевести деньги оператору
3. `/markpaid @username` — отметить выплаченным

---

## Команды быстрой справки

| Команда | Когда использовать |
|---------|-------------------|
| `/stats` | Каждый день — общая картина |
| `/sourcestats today` | Утром — есть ли новый трафик |
| `/sourcefunnel 7d` | Раз в неделю — воронка по источникам |
| `/campaignstats avito 7d` | Раз в неделю — сравнение объявлений |
| `/operatorstats` | Раз в неделю — кто из операторов работает |
| `/payouts` | Перед выплатами операторам |
| `/operators` | Когда нет ставок — проверить что операторы активны |
| `/disputes` | Если есть споры |

---

## Что НЕ надо делать ежедневно

- Не смотри `/sourcefunnel` каждый день — там нужна неделя данных минимум
- Не паникуй если день 1–2 нет регистраций — дай объявлениям выйти в поиск
- Не останавливай кампании раньше 7 дней без весомой причины
