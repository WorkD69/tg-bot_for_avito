# Авито — Пакет креативов

## Объявление: структура

**Заголовок объявления (до 50 символов):**
```
Решение учебных задач в Telegram — быстро
```

**Описание объявления:**
```
Telegram-бот Studario поможет решить задачи по математике, физике, программированию, экономике и другим предметам.

Как работает:
1. Отправляете задание боту
2. Несколько операторов делают ставки — вы получаете лучшую цену
3. Оплачиваете онлайн
4. Получаете готовое решение прямо в Telegram

✓ Живые специалисты, не нейросети
✓ Результат с пошаговыми пояснениями
✓ Если что-то не так — открывайте спор

Пишите в Telegram: @studario_bot [замените на вашу ссылку]
Поддержка: @studario_support
```

**Категория на Авито:** Услуги → Обучение, репетиторство → Репетиторы

## 5 креативов — детальное описание

### Креатив 1: Главная обложка — "Решим задачу за вас"

**Цель:** Остановить скролл, донести главный оффер за 2 секунды

**Файл:** `assets/branding/avito_01.svg`

**Текст на картинке:**
```
Решим задачу
за вас

Математика · Физика · Программирование
Экономика · Химия · Статистика

✓ Аукцион цен — платите меньше
✓ Решение в Telegram — никаких звонков
✓ Не устраивает — оспорьте бесплатно

[Написать в Telegram →]
```

**Дизайн:** Тёмно-синий фон, оранжевый акцент на "за вас", оранжевая кнопка CTA. Крупный декоративный S справа.

**Правила:**
- НЕ писать конкретные цены ("от 300 руб")
- НЕ писать "гарантированно", "100%"
- НЕ перечислять все предметы — только ключевые

## Экспорт SVG → PNG для загрузки на Авито

**Метод 1 — Браузер:**
1. Открыть SVG файл в Chrome
2. Нажать Ctrl+P → Сохранить как PDF
3. Конвертировать PDF → PNG онлайн (ilovepdf.com, etc.)

**Метод 2 — Inkscape (бесплатно):**
```bash
inkscape avito_01.svg --export-type=png --export-dpi=150 -o avito_01.png
```

**Метод 3 — Figma:**
1. File → Import → выбрать SVG
2. Export → PNG → 2x

**Рекомендуемое разрешение:** 1200×800px при 150 DPI = хорошее качество на мобиле

## Чего нельзя писать на Авито

- "Помогаю с контрольными, курсовыми, дипломами" — нарушает правила Авито
- "Выполнение учебных работ" — прямое указание на академическую нечестность
- Конкретные цены без контекста — снижает воспринимаемую ценность
- "100% успех", "гарантия сдачи" — нельзя гарантировать

**Формулировки, которые работают:**
- "Решение задач", "помощь с задачами", "разбор задач"
- "Пояснения и решения"
- "Помощь в понимании материала"
