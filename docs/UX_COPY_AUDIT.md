# UX и копирайт бота — Аудит и улучшения

## Методология

Аудит проведён по всем клиентским сценариям:
- Создание заявки (4 шага)
- Просмотр текущих заявок
- Просмотр истории
- Оплата (Robokassa и ручная)
- Спор
- Отзыв
- "Как это работает"

---

## Что сейчас работает хорошо — не трогать

1. **Подтверждение заявки** — "Операторы уже видят её и подбирают цену — как только кто-то откликнется, вы сразу получите уведомление" → **верный тон, нет лишних обещаний**

2. **Кнопка /cancel** — работает предсказуемо, ответ понятный

3. **Идемпотентность кнопок** — "Оплата уже зафиксирована — ждите подтверждения" → клиент не путается

4. **Паджинация отзывов** — in-place edit, правильно

5. **FSM guards** — объяснения типа "Вы уже выполняете другое действие" → понятно

## Проблемы найдены — что улучшить

### 🔴 Проблема 1: Карточки заявок — визуальная каша без структуры

**Текущий вид format_client_card:**
```
📌 Заявка №5
Статус: В ожидании
Дата создания: 13.04.2026 14:30 МСК
Дедлайн: 20.04.2026
Желаемый бюджет: 1500 ₽
Прикреплённых файлов: нет
История взаимодействия:
  Сообщений пока нет
```

**Проблемы:**
- Поля идут подряд без группировки — взгляд не цепляется
- "Прикреплённых файлов: нет" — шум, никакой ценности для клиента
- "Сообщений пока нет" — одинокая строка в конце смотрится брошено
- Нет пояснения что значит статус (особенно "В ожидании" — клиент не знает что происходит)

**Улучшение внедрено в formatters.py** — см. раздел "Изменения в коде"

---

### 🟡 Проблема 2: Шаг "Комментарий" — непонятный дефис

**Текущий текст:**

## Что НЕ трогаем

| Место | Почему не трогаем |
|-------|------------------|
| Логика operator FSM | Рабочая, сложная, риск поломки |
| Система ставок | Бизнес-логика, трогать только осознанно |
| Платёжный flow | Критично, менять только с полным тестированием |
| Форматтер оператора | Операторы привыкли, не путать |
| Admin команды | Работают, трогать нет смысла |

## Тональность: резюме

**Делать:**
- Конкретные следующие шаги
- Короткие сообщения (до 4 строк в норме)
- Эмодзи в начале строки как иконка, не внутри текста

**Не делать:**
- Обещания с "100%", "гарантируем", "всегда"
- "Ваш запрос принят и будет обработан" — чиновничий язык
- Избыточные объяснения где всё и так понятно
