## Где публиковать (бесплатно)

### ВКонтакте — паблики и сообщества

| Сообщество | Ссылка | Формат |
|-----------|--------|--------|
| Типичный студент | vk.com/typical_student | Пост в комментарии / предложить новость |
| Студенческая жизнь | vk.com/students_life | Комментарии под постами |
| Подслушано Студенты | искать "Подслушано [твой город]" | Отправить историю через форму |
| Лайфхак студента | vk.com/lifehack_student | Комментарии |
| Помогите с учёбой | искать "помощь с учёбой" в поиске ВК | Пост в стену (открытые группы) |
| Университетские группы | поиск: "[название вуза] студенты" | Посты / комментарии |
| Чаты факультетов | поиск: "[факультет] [вуз] помощь" | Стена или предложенные записи |

**Как найти ещё:** в поиске ВК вводи "студенты помощь учёба [город]" — смотри открытые группы, куда можно публиковать записи или писать в обсуждения.

### Telegram — чаты и каналы

| Что искать | Как найти |
|-----------|----------|
| Чаты студентов конкретных вузов | В поиске Telegram: "[вуз] чат", "[вуз] общага", "[факультет] помощь" |

| Региональные студенческие чаты | "студенты [город]", "университет [город]" |
| Чаты по предметам | "матан помощь", "физика студенты", "экономика задачи" |
| Доски объявлений студентов | "объявления студенты [город]" |

**Лайфхак:** зайди в чаты вузов своего города — там самая живая аудитория. Такие чаты есть почти в каждом университете, просто найди своих знакомых оттуда и попроси кинуть ссылку.

## 5 готовых сообщений (копируй и отправляй)

### Сообщение 1 — Прямой оффер (для чатов и групп)

```
Привет! Запустил сервис помощи студентам с учебными задачами — @studario1_bot

Как работает:
→ Пишешь задачу в бот
→ Получаешь цену и дедлайн
→ Оплачиваешь — получаешь решение

Работаем с матаном, физикой, статистикой, эконометрикой, программированием и другими точными науками. Задачи берём даже в ночь перед сдачей.

Если застрял с задачей — пиши: @studario1_bot
```

Есть решение для ситуации "23:58, сдача в 8 утра, задачи непонятны"

Запустил Telegram-бота для студентов: кидаешь задачу — живой специалист решает с оформлением.

### Сообщение 3 — Через сравнение с ChatGPT (работает в дискуссиях)

```
ChatGPT ошибается в каждой третьей нетиповой задаче — проверял лично.

Авторские задачи с кафедры нейросеть не знает. Она видит похожую структуру и галлюцинирует — выдаёт уверенный ответ с неверными формулами.

Поэтому сделал @studario1_bot — там живые специалисты, которые решают именно твои задачи, а не "похожие из интернета"
```

## Как ещё найти клиентов бесплатно

### 1. Личные связи — самый быстрый старт
- Напиши 10–15 знакомым студентам прямо сейчас
- Попроси их переслать сообщение в свои учебные чаты
- Один репост в студенческий чат на 200 человек = реальные заявки

### 2. Комментарии под чужими постами
Ищи посты типа "помогите с матаном", "кто решит задачу по статистике" в студенческих группах ВК и чатах Telegram — и отвечай там с упоминанием бота. Это работает лучше рекламы.

### 3. Авито (уже есть)
Объявление будет набирать показы постепенно — просматривай статистику раз в 3 дня и поднимай при необходимости.

### 4. Отзыв → следующий клиент
После каждого выполненного заказа — проси клиента написать в учебный чат что-то вроде "этот бот реально помог". Один довольный студент = 2–3 новых.

### 5. Telegram Search
В поиске Telegram пиши: "помогите с задачей", "решить задачу срочно", "кто может помочь с матаном" — там живые люди прямо сейчас ищут помощь. Отвечай им напрямую.

### 6. Сезонность — используй её
Самый горячий спрос:
- **Январь / июнь** — сессия, максимальный трафик
- **Конец каждого месяца** — сдача контрольных
- **Воскресенье вечер** — дедлайн в понедельник

Планируй активность именно в эти окна.

## Что писать в первый день (план на 2 часа)

1. Напиши 10 знакомым студентам лично — попроси переслать
2. Найди 3–5 студенческих Telegram-чатов своего города — кинь Сообщение 1 или 4
3. Зайди в ВК и найди 2–3 открытые студенческие группы — предложи запись или напиши в комментарии
4. Поищи в Telegram людей с вопросами "помогите решить задачу" — ответь им

Этого достаточно для первых заявок.
