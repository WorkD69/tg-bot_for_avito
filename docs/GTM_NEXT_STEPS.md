# Go-to-Market: следующие шаги

## Стратегия выхода на рынок

**Цель первого месяца:** 10–15 выполненных заявок, 5+ отзывов, подтверждённый спрос.

Не масштаб. Не автоматизация. Не реклама. Только ручная проверка: платит ли кто-то деньги за нашу услугу.

---

## Перед запуском (день 0)

### 1. Деплой на VPS (если ещё не сделано — критично)

ngrok не подходит для продакшна: перезапускается, меняет URL, падает.

**Минимальный VPS:** DigitalOcean / Hetzner / Reg.ru — $5–6/мес, 1GB RAM достаточно.

```bash
# На VPS: клонировать репо, настроить .env с реальными данными,
# поднять docker-compose up -d
# Настроить webhook с постоянным HTTPS-доменом (Caddy или nginx + certbot)
```

**Без этого не запускаться** — нестабильный бот хуже чем никакого.

### 2. Ручная верификация @studario_support

Telegram не даёт сразу username для новых аккаунтов — нужен номер телефона с историей.

**Варианты:**
- Второй личный номер (если есть)
- Купить SIM только для этого аккаунта
- Использовать существующий "рабочий" аккаунт, сменить username

После создания аккаунта:
- Установить аватар из `assets/branding/support_avatar.svg`
- Написать несколько сообщений в разные чаты — чтобы аккаунт не выглядел свежесозданным
- Добавить в личное Bio: "Поддержка Studario · studario_bot"

### 3. Проверить бот перед первым клиентом

Пройти полный flow самому:
- Создать заявку через бота (все 4 шага)
- Принять заявку как оператор (с другого аккаунта)
- Оплатить (тестовый режим Robokassa или кнопку "Я оплатил")
- Загрузить решение
- Оставить отзыв

## День 1: Что публиковать первым

**Правильный порядок:**

1. **Запустить объявление на Авито** — это основной источник первого трафика.
   - Авито даёт бесплатный показ новых объявлений первые дни
   - Не платить за продвижение сразу — проверьте органику

2. **Опубликовать первый пост в Telegram-канале** — закреплённый + продающий.
   - Поделиться ссылкой на канал в своих чатах, попросить 5–10 человек подписаться

3. **Поддержка @studario_support готова** — аккаунт активен, аватар установлен

**НЕ запускать одновременно** рекламу, Авито, 10 постов в канале — сначала проверить органику.

## Первые 24 часа: 3 приоритетных действия

1. **Создать и опубликовать объявление на Авито** с 5 загруженными фото
2. **Установить аватарки** боту и @studario_support  
3. **Пройти тестовый полный flow** — убедиться что всё работает под нагрузкой

---

## Первые 7 дней: 3 приоритетных действия

1. **Ответить на каждое обращение вручную и быстро** — скорость ответа критична для первых конверсий
2. **Опубликовать 2 поста в канале** — как работает + первый кейс (даже синтетический на основе тестового заказа)
3. **Собрать первый реальный отзыв** — попросить первого клиента оставить отзыв прямо в боте, похвалить его за это

## День 1–3: Аналитика (за чем следить)

**Нормально:** 0–3 обращения в день с Авито. Конверсия в заявку 20–40%.

**Красные флаги:**
- Нет ни одного обращения за 3 дня → проблема с заголовком/фото объявления. Менять заголовок и/или первую фотографию
- Обращения есть, но не конвертируются → спросить напрямую "что остановило". Обычно: цена, доверие, непонятный процесс
- Бот падает/не отвечает → VPS не настроен или webhook упал. Проверить `docker-compose logs -f bot`

**Что мерить:**
- Сколько написали в Авито / в бота
- Сколько дошли до создания заявки
- Сколько оплатили
- Сколько оставили отзыв

Записывать в таблицу вручную первые 2 недели — аналитика через бота позже.

## День 3–7: Первые клиенты

**Что делать с каждым клиентом:**

1. Быть оператором сами первые 5–10 заявок — понять реальный flow изнутри
2. После выполнения — вручную написать клиенту в поддержку: "Привет, как всё прошло?"
3. Попросить оставить отзыв в боте
4. Если клиент с Авито — и avito_profile_url настроен, бот сам предложит отзыв на Авито

**Когда нанимать первого оператора:**
- После 5+ успешных заявок когда понятен тип задач
- Оператор должен пройти тест: решить одну задачу под вашим контролем

## Когда масштабировать

**Сигналы к масштабированию:**
- 10+ заявок в неделю органически
- Конверсия из Авито > 30% (написали → создали заявку)
- Хотя бы 3 повторных клиента
- Операторы справляются, нет очереди

**Тогда:** платное продвижение на Авито, реклама в Telegram-каналах для студентов.

**Критические ошибки на старте:**
- Запустить рекламу до того как проверен product-market fit → сжечь деньги
- Игнорировать первые жалобы → потеря репутации
- Медленно отвечать на Авито (> 2–3 часов) → потеря клиента
- Брать задачи, которые оператор не может выполнить → спор, плохой отзыв

## Стратегия отзывов — итог

**Сейчас (до Авито-листинга):**
- Система внутренних отзывов работает
- Авито-нудж настроен (активируется когда заполните AVITO_PROFILE_URL)
- Ничего дополнительно не нужно

**После первых 5 клиентов:**
- Попросить оставить отзыв на Авито напрямую в переписке (вручную)
- Использовать реальные отзывы для замены шаблонных текстов в avito_05.svg

**После 10+ клиентов:**
- Опубликовать 3 кейса в Telegram-канале
- Обновить Авито-объявление с реальными отзывами в фото 5

**Не делать:**
- Не просить отзывы у клиентов tg_channel и direct на Авито — они там не зарегистрированы или это выглядит странно
- Не публиковать отзывы без удаления персональных данных
- Не накручивать отзывы — легко определяется и ломает доверие навсегда
