# Studario — Сообщение существующим клиентам

Отправляй тем, кому уже решал задачи раньше (лично, через Авито, или как угодно).

---

## Сообщение (копировать целиком)

```
Привет! Это [твоё имя], решал тебе задачи раньше.

Запустил нормальный сервис для этого — теперь всё через Telegram-бота:
👉 t.me/studario1_bot

Там проще: кидаешь задачу, указываешь дедлайн и бюджет — специалист берёт в работу. Не надо договариваться в переписке, цена сразу понятна.

Если снова что-то будет — пиши туда, разберёмся быстро
```

---

## Примечания

- Короткое и без лишнего — они тебя уже знают, не нужно объяснять что такое сервис
- Не пиши "реклама" или "скидка" — это личное обращение, не рассылка
- Если хочешь — можешь добавить одну строчку про конкретную задачу которую решал им: "помнишь, решал тебе [предмет] в [месяц]?" — это повышает отклик
