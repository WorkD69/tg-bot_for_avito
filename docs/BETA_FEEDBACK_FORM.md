# Studario — Beta Feedback

Файл содержит всё для запуска бета-тестирования:
1. Сопроводительное сообщение друзьям
2. Вопросы для Google Form (с типами и вариантами ответов)

---

## Сопроводительное сообщение

Отправь друзьям вместе со ссылкой на бот и форму:

```
Привет! Я запускаю сервис для помощи студентам с задачами — всё через Telegram.

Можешь протестировать бота? Это займёт 5–10 минут:

1. Открой бота: t.me/studario1_bot
2. Напиши /start и создай тестовую заявку (можешь написать любую учебную задачу — реальную или выдуманную)
3. Посмотри как это работает изнутри

После — заполни короткую форму на 3 минуты, это очень поможет:
https://docs.google.com/forms/d/e/1FAIpQLSenaC54CPtbibOWAgiYXfaGLU79xDvd9beUdq6pubvW0tE-tQ/viewform

Буду благодарен за честный фидбек — особенно если что-то было непонятно или пошло не так 🙏
```

## Google Form — инструкция по созданию

**Ссылка:** forms.google.com → кнопка «+» → Новая форма

**Название формы:**
```
Studario — тестирование бота
```

**Описание формы:**
```
Ты попробовал наш Telegram-бот @studario1_bot. Заполни форму — это займёт 3 минуты и поможет нам понять что улучшить. Спасибо!
```

## Вопросы (копируй по одному)

---

### Вопрос 1
**Тип:** Один вариант ответа

**Текст:**
```
Ты смог(ла) создать заявку без проблем?
```

**Варианты:**
```
Да, всё понятно и просто
Было непонятно, но разобрался(ась)
Застрял(а) — не понял(а) что делать
```

---

### Вопрос 2
**Тип:** Несколько вариантов ответа (чекбоксы)

**Текст:**
```
На каком шаге было труднее всего или что-то пошло не так?
```

**Варианты:**
```

Когда прикреплял(а) файл с заданием
Когда указывал(а) дедлайн или бюджет
Когда ждал(а) ответа от оператора
Всё прошло гладко
```

## Настройки формы после создания

- **Сбор email:** отключить (анонимно — ответят честнее)
- **Показывать прогресс:** включить
- **Разрешить редактировать ответы:** включить
- **Подтверждение после отправки:** написать `Спасибо! Твой фидбек очень поможет 🙏`
- Когда соберёшь ответы — смотри в Google Sheets (кнопка «Ответы» → иконка таблицы)
