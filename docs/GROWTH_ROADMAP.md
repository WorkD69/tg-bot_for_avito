# Growth Roadmap — Что реально повысит бизнес

## Консультация продукт-менеджера

Разобраны 5 ключевых метрик: доверие, удобство, конверсия, удержание, повторные заказы.

---

## ДО ЗАПУСКА — критично сделать руками

### 1. VPS вместо ngrok
**Влияние:** без этого нельзя запускаться. Нестабильный бот = нет бизнеса.

### 2. Аватарки бота и поддержки
**Влияние:** доверие +30%. Бот без аватара выглядит как фишинг.
**Файлы готовы:** `assets/branding/bot_avatar.svg`, `support_avatar.svg`

### 3. Объявление на Авито с 5 фото
**Влияние:** это главный канал привлечения на старте.
**Файлы готовы:** `assets/branding/avito_01.svg` ... `avito_05.svg`

### 4. @studario_support живой и отвечает
**Влияние:** снимает страх "куда обращаться если что". Критично для конверсии.

### 5. Deeplink для Авито настроен
**Влияние:** атрибуция — поймёте откуда приходят клиенты.
```
t.me/ваш_бот?start=avito
```
Добавить в описание объявления на Авито. В базе уже сохранится `user.source = "avito"`.

## ПОСЛЕ ПЕРВЫХ КЛИЕНТОВ (5–10 заявок)

### 6. Публичные кейсы в Telegram-канале
**Влияние:** доверие + конверсия. Клиент с Авито проверяет канал.
**Шаблоны готовы:** `assets/branding/case_card_0N.svg`

### 7. Реальные отзывы заменяют шаблонные в avito_05.svg
**Влияние:** social proof с конкретными историями > красивая картинка

### 8. Добавить предмет/тип задачи в приветственное сообщение FSM
**Влияние:** удобство. Сейчас клиент сразу отправляет файлы — без контекста.
```
# Например: добавить шаг "выберите предмет" перед загрузкой файлов
# Не делать сейчас — усложняет flow, нужно тестировать
```
**Статус:** ⏳ После 10+ заявок, когда понятен реальный тип задач

### 9. Уведомление "оператор взял заявку"
**Влияние:** удержание. Клиент не знает что происходит в auction window.
```
# Когда оператор делает bid == budget (auto-assign):
# Сразу уведомить клиента "Оператор взял вашу задачу! Ожидайте решения"
# Проверить: возможно уже есть, если нет — добавить
```
**Статус:** ⏳ Low-risk улучшение, добавить в ближайшую итерацию

### 10. Мини-онбординг для новых клиентов
**Влияние:** конверсия первый раз → второй раз.
```
# После первой завершённой заявки:
# "Всё прошло хорошо? Мы рады! 
#  Если будут задачи — создайте ещё одну прямо здесь →"
# Inline кнопка "➕ Новая заявка" — уже реализована!
```
**Статус:** ✅ Кнопка "Создать ещё заявку" уже есть в completed карточке

## НЕ НУЖНО СЕЙЧАС

### Реферальная программа
**Почему нет:** реферальная программа работает когда уже есть поток. До 50 заявок/мес — рано.

### A/B тестирование
**Почему нет:** для A/B нужен трафик. На старте нет выборки.

### Рассылки / broadcast
**Почему нет:** клиентская база слишком мала для рассылок, это спам.

### Расширение на другие предметы / типы работ
**Почему нет:** сначала сделайте идеально текущее. Расширение = сложность операций.

### Платное продвижение на Авито
**Почему нет:** на старте — проверить органику. Платить за трафик до понимания конверсии = слив денег.

### Автоматизация операторского flow
**Почему нет:** пока операторов мало, ручное управление лучше. Автоматизация нужна при 20+ заявок/день.

### Публичные профили операторов
**Почему нет:** усложняет доверие к бренду (клиент привязывается к конкретному оператору). Рассматривать только при 5+ операторах.
