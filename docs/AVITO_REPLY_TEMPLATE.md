# Studario — Шаблон ответа клиенту в Авито

Копируй и отправляй любому, кто написал в Авито по поводу задачи.

---

## Сообщение (копировать целиком)

```
Привет! Да, берём в работу.

Для оформления заявки — напиши нашему боту в Telegram, там это займёт 2 минуты:
👉 t.me/studario1_bot?start=avito

Там нужно будет прикрепить файл с заданием (или написать условие текстом), указать дедлайн и желаемую стоимость. После этого специалист свяжется с тобой и уточнит детали.

Работаем с математикой, физикой, статистикой, эконометрикой, программированием и другими точными науками. Срочные задачи тоже берём.
```

---

## Примечания

- Ссылка `?start=avito` — метка для статистики, по ней видно сколько клиентов пришло именно с Авито
- Если клиент не пользуется Telegram — можно уточнить задачу прямо в Авито-чате, а потом ввести вручную как оператор
- Если клиент спрашивает цену сразу — отвечай: "Цена зависит от задачи и дедлайна, в боте назовём конкретную сумму после просмотра задания"
