# Marketing Launch Pack

Операционный пакет для запуска первых реальных кампаний.
Всё готово к использованию без дополнительной настройки.

**Бот:** `t.me/studario1_bot`
**Тип сервиса:** решение задач по точным наукам — математика, физика, программирование

---

## 1. Готовые deeplink'и

### Схема нейминга

```
t.me/studario1_bot?start={source}_{campaign_id}
```

Правила campaign_id:
- Только латиница, цифры, дефис (`-`), нижнее подчёркивание (`_`)
- Без пробелов и кириллицы
- Смысловое: `ad1`, `post_june`, `story1` — не `test`, не `123`
- Длина до 32 символов

### Авито — 5 deeplink'ов

| ID кампании | Ссылка | Назначение |
|------------|--------|-----------|
| `avito_ad1` | `t.me/studario1_bot?start=avito_ad1` | Основное объявление — короткий оффер |
| `avito_ad2` | `t.me/studario1_bot?start=avito_ad2` | Объявление с примерами предметов |
| `avito_ad3` | `t.me/studario1_bot?start=avito_ad3` | Объявление с ценой |
| `avito_ad4` | `t.me/studario1_bot?start=avito_ad4` | Объявление с дедлайном ("к завтрашнему дню") |
| `avito_ad5` | `t.me/studario1_bot?start=avito_ad5` | Объявление с социальным доказательством |

### Telegram-канал — 3 deeplink'а

| ID кампании | Ссылка | Назначение |
|------------|--------|-----------|
| `tg_channel_post1` | `t.me/studario1_bot?start=tg_channel_post1` | Первый пост — знакомство с сервисом |
| `tg_channel_post2` | `t.me/studario1_bot?start=tg_channel_post2` | Второй пост — кейс или пример задачи |
| `tg_channel_story1` | `t.me/studario1_bot?start=tg_channel_story1` | Пост в Stories или закреплённый |

### Прямые / ручные — 2 deeplink'а

| ID кампании | Ссылка | Назначение |
|------------|--------|-----------|
| `direct_manual1` | `t.me/studario1_bot?start=direct_manual1` | Ручная рассылка в личку / VK / WhatsApp |
| `direct_chat1` | `t.me/studario1_bot?start=direct_chat1` | Рекомендация в чатах / группах |

### Как не запутаться в кампаниях

1. **Один файл — одна ссылка.** Запиши в таблицу (Google Sheets / Notion): дата публикации, площадка, объявление, ссылка.
2. **Никогда не меняй ссылку в уже работающем объявлении** — потеряешь атрибуцию прошлых пользователей.
3. **Создавай новый campaign_id для каждого нового текста.** Обновил текст на Авито — заведи `avito_ad2`, не переиспользуй `avito_ad1`.
4. **Источник всегда читаем:** `avito_*` — Авито, `tg_channel_*` — канал, `direct_*` — всё остальное.

## 3. Операционный план на 14 дней

### День 0 — Публикация

- [ ] Разместить все 5 объявлений на Авито (с разными campaign_id)
- [ ] Опубликовать пост 1 в Telegram-канале (`tg_channel_post1`)
- [ ] Проверить что ссылки открываются и бот отвечает welcome-сообщением
- [ ] Написать себе в боте с каждой ссылкой — убедиться что welcome корректный
- [ ] Запустить `/stats` — зафиксировать baseline (сколько пользователей, заявок)

### День 3 — Первый чекин

Команды:
```
/sourcestats today
/campaignstats avito 7d
```

Что смотрим:
- Есть ли вообще трафик? (хотя бы 2–5 регистраций)
- Какое объявление Авито дало больше пришедших?
- Если 0 регистраций — проблема в ссылке или объявлении, перепроверить

### День 7 — Определить первого победителя

Команды:
```
/campaignstats avito 7d
/sourcefunnel 7d
```

Что смотрим:
- Какой campaign_id дал наибольший completion rate?
- Какой источник лучше конвертирует в заявки?
- Если есть явный лидер — удваивай ставку на то объявление

Решения по результатам:
- Лучший avito campaign → поднять в поиске, взять похожий текст для нового объявления
- Худший campaign (0 заявок при 10+ регистрациях) → отключить или переписать
- Если tg_channel лучше avito → создать больше контента для канала

### День 14 — Итоговый анализ

Команды:
```
/sourcefunnel 14d
/campaignstats 14d
/stats
```

Что смотрим:
- Где выручка? (gross revenue по источникам)
- Completion rate по каждому кампанию
- Сколько follow-up ушло (`📬 Follow-up отправлено`)
- Окупаются ли затраты на рекламу?

Действия:
- Лучший по completion rate → масштабировать бюджет
- Источник с выручкой > 0 → вкладывать больше
- Объявление с registration > 20, но заявками = 0 → плохой оффер, переписать

## 4. Аналитические команды для запуска

### Порядок ежедневного просмотра

1. `/stats` — быстрый snapshot: сколько заявок в работе, есть ли проблемы
2. `/sourcestats today` — сколько новых пользователей сегодня и откуда
3. `/campaignstats avito 7d` — какое объявление работает лучше

### Главная команда — `/sourcefunnel 7d`

Показывает полную воронку: зарегистрировались → создали заявку → оплатили → завершили.

Как читать:
- **Completion rate > 40%** — хорошо, канал работает
- **Completion rate 20–40%** — нормально, есть куда расти
- **Completion rate < 20%** — проблема: либо нецелевой трафик, либо высокая цена

### `/campaignstats [source] [period]` — для сравнения объявлений

```
/campaignstats avito 7d      — сравниваю свои объявления между собой
/campaignstats tg_channel    — что даёт канал
```

Как читать:
- **Paid/Orders < 40%** — клиенты уходят на этапе цены → цена слишком высокая
- **Orders/Registered < 30%** — оффер слабый → плохое объявление или не те люди
- **Много registered, 0 orders** — критическая проблема: пользователи не понимают что делать

### Пороги, которые должны насторожить

| Показатель | Тревожный порог | Что делать |
|-----------|----------------|-----------|
| Регистрации за 7 дней | < 5 | Проверить ссылки, поднять объявления |
| Orders / Registered | < 20% | Переписать объявление, улучшить welcome |
| Paid / Orders | < 35% | Снизить цену или улучшить объяснение ценности |
| Completion / Paid | < 70% | Проблема с качеством — обратная связь операторам |
| Completion rate | < 15% за 14 дней | Пересмотреть весь подход |

### `/stats` — что смотреть ежедневно

- `📬 Follow-up отправлено: N` — растёт? Значит пользователи завершают задачи
- `⏳ К выплате операторам` — много? Не забыть выплатить
- `⚖️ Споров: N` — если > 2 за неделю — смотреть что не так с операторами

## 5. Go-to-market checklist (пройти за 5 минут перед запуском)

### Ссылки и campaign_id

- [ ] Все 10 deeplink'ов создал и записал в таблицу (source, campaign, площадка, дата)
- [ ] Ни одна ссылка не дублируется (разные campaign_id для разных объявлений)
- [ ] Проверил каждую ссылку: `t.me/studario1_bot?start=avito_ad1` — открывается и бот отвечает

### Бот работает

- [ ] `/start` без параметра — бот отвечает нейтральным welcome
- [ ] `/start avito_ad1` — бот отвечает avito-специфичным welcome с упоминанием "Авито"
- [ ] `/start tg_channel_post1` — бот отвечает channel-специфичным welcome
- [ ] Кнопка "Создать заявку" работает — FSM запускается
- [ ] Бот не падает при создании заявки (проверить в логах: `docker-compose logs bot`)

### Аналитика

- [ ] `/sourcestats` — отвечает без ошибок (даже если пусто)
- [ ] `/sourcefunnel` — отвечает без ошибок
- [ ] `/campaignstats` — отвечает без ошибок
- [ ] `/stats` — показывает `📬 Follow-up отправлено:` строку

### Follow-up

- [ ] После завершения заявки job появляется: `SELECT id FROM apscheduler_jobs WHERE id LIKE 'followup_%';`
- [ ] `/stats` показывает follow-up counter

### Команды админа

- [ ] `/addoperator` — есть хотя бы один активный оператор
- [ ] `/operators` — показывает список
- [ ] `/stats` — доступна и отвечает

### Базовая ручная проверка

- [ ] Создать одну тестовую заявку как клиент, довести до оплаты
- [ ] Оператор видит заявку в группе
- [ ] После завершения — follow-up job запланирован в scheduler
- [ ] Клиент получает сообщение о завершении
