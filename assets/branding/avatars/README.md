# Studario — Аватарки бренда

Папка содержит все аватарки для каналов и ботов Studario.

## Файлы

| Файл | Использование | Размер |
|------|--------------|--------|
| `studario_main_dark.png` | Аватар основного бота @studariobot | 512×512 |
| `studario_main_teal.png` | Аватар основного бота — альтернатив (бирюзовый) | 512×512 |
| `studario_support.png` | Аватар бота поддержки @studario_support | 512×512 |
| `studario_s_neon.png` | Неоновая S — для использования в постах/баннерах | 440×640 |

## Стиль

Все аватарки выполнены в едином стиле:
- Тёмный фон (#0a0a12 — #13131f)
- Геометрическая буква S с эффектом свечения
- Математические символы как текстурный фон (∫ Σ π Δ x² λ)
- Надпись "STUDARIO" / "ПОДДЕРЖКА" внизу

## Как установить аватар боту

1. Открыть @BotFather → /mybots → выбрать бота → Edit Bot → Edit Botpic
2. Загрузить нужный PNG файл

## Как установить аватар @studario_support

1. Зайти в аккаунт @studario_support
2. Настройки → Изменить профиль → Фото
3. Загрузить `studario_support.png`
