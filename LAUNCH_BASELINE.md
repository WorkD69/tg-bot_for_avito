## Как использовать этот baseline

1. **На день 7** запусти `/stats` и сравни с этими числами — насколько выросли регистрации и заявки
2. **На день 14** запусти `/sourcefunnel 14d` — это будут первые реальные данные по воронке
3. Для корректного сравнения всегда используй период `7d` или `14d` — не "всё время", т.к. исторические данные без attribution

## SQL для самопроверки

```sql
-- Текущие пользователи по источникам
SELECT source, campaign, COUNT(*) FROM users GROUP BY source, campaign;

-- Заявки по статусам
SELECT status, COUNT(*) FROM orders GROUP BY status;

-- Финансовый снимок
SELECT
    COALESCE(SUM(gross_amount), 0) as gross,
    COALESCE(SUM(CASE WHEN status IN ('pending','adjusted') THEN operator_share END), 0) as payable,
    COALESCE(SUM(CASE WHEN status = 'paid' THEN operator_share END), 0) as paid
FROM operator_earnings;
```
