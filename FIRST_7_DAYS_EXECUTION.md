# First 7 Days Execution Guide

Практический гайд по запуску и первой неделе работы.
Конкретные действия, конкретные решения — без теории.

**Бот:** `t.me/studario1_bot`

---

## День 0 — Что публикуем

### Запускаем в первую очередь (обязательно)

**1. Авито — 2 объявления одновременно:**
- `avito_ad1` — короткий оффер (Вариант 1 из MARKETING_LAUNCH_PACK.md)
- `avito_ad3` — с ценой (Вариант 3)

Почему именно эти два:
- `ad1` — универсальный, работает в любой категории
- `ad3` — с ценой отсекает нецелевых, выше конверсия в заявку

**2. Telegram-канал — 1 пост:**
- `tg_channel_post1` — знакомство с сервисом

### Что НЕ запускать в день 0

- `avito_ad2`, `avito_ad4`, `avito_ad5` — не нужны сразу, сначала проверь базовую конверсию
- `tg_channel_post2`, `tg_channel_story1` — подождут день 7, когда будет что показывать
- `direct_*` — только когда есть кому рассылать (чаты, знакомые)

### Технический чеклист дня 0

- [ ] Скопировать ссылки из CAMPAIGN_TRACKER_TEMPLATE.md
- [ ] Вставить в объявления Авито вместо обычного телефона/ссылки
- [ ] Опубликовать пост в канале
- [ ] Проверить каждую ссылку вручную: открыть → бот ответил welcome с "Авито" или "канала"
- [ ] Обновить статус в трекере: `draft` → `live`
- [ ] Записать `/stats` baseline (или открыть LAUNCH_BASELINE.md)
- [ ] Убедиться что есть активный оператор: `/operators`

## День 3 — Первый сигнал

### Что запустить

```
/sourcestats today
/sourcestats 7d
/campaignstats avito 7d
```

### Как интерпретировать

**Хороший сигнал (продолжай):**
- Регистраций ≥ 3 за 3 дня
- Хотя бы 1 заявка создана
- Оба объявления дали хотя бы по 1 регистрации

**Нейтральный (подождать до дня 7):**
- 1–2 регистрации, 0 заявок
- Только один campaign_id дал трафик

**Плохой сигнал (действуй сразу):**
- 0 регистраций за 3 дня → объявления не показываются или ссылки сломаны
  - Проверить: открыть ссылку вручную, убедиться что объявления в "Активных"
  - Поднять объявления в топ на Авито (платный буст)
- Регистрации есть, но все `source=unknown` → deeplink не работает
  - Проверить: `/start avito_ad1` в боте → должен показать "Авито" в welcome

### Что заполнить в трекере

Открой CAMPAIGN_TRACKER_TEMPLATE.md → заполни колонку `day3_result` для каждой живой кампании.

## День 7 — Выбрать победителя

### Что запустить

```
/campaignstats avito 7d
/sourcefunnel 7d
/stats
```

### Как выбрать победителя

Победитель определяется по **completion rate** (Заявки → Завершено), а не по числу регистраций.

| Ситуация | Решение |
|----------|---------|
| `avito_ad1` completion rate > `avito_ad3` | Масштабируй `avito_ad1`, останови `avito_ad3` |
| `avito_ad3` completion rate > `avito_ad1` | Масштабируй `avito_ad3`, останови `avito_ad1` |
| Оба completion rate = 0, но заявки есть | Ещё рано, подожди до дня 14 |
| Оба дали 0 заявок при ≥ 5 регистрациях | Плохой оффер → переписать текст |
| `tg_channel` conversion rate выше, чем `avito` | Сделать ещё 1–2 поста в канал |

### Что делать с победителем

1. Поднять в поиске на Авито (бюджет)
2. Запустить похожий текст с новым campaign_id (`avito_ad1b` или `avito_ad6`)
3. Включить `avito_ad2` — ещё один вариант текста для сравнения

### Что запустить на день 7–14

Если базовые кампании дают хоть какой-то результат:
- `tg_channel_post2` — второй пост в канал с кейсом
- `avito_ad2` — третье объявление на Авито
- `direct_manual1` — начать отправлять ссылку в тематические чаты

## Когда остановить кампанию

Останавливай если за **7 дней активной работы** кампания показала:

| Критерий | Действие |
|----------|----------|
| Регистраций = 0 | Немедленно остановить, разобраться с размещением |
| Регистраций ≥ 5, заявок = 0 | Остановить или переписать текст (плохой оффер) |
| Регистрации + заявки есть, но Paid/Orders < 20% | Пересмотреть ценообразование |
| Completion rate < 10% при ≥ 5 завершённых | Проблема с качеством операторов |

**Не останавливай** кампанию раньше 5–7 дней — у объявлений на Авито есть инкубационный период.

## Частые ошибки первой недели

**Ошибка 1:** Запустить все 5 объявлений сразу
→ Нельзя понять что работает. Старт с 2 максимум.

**Ошибка 2:** Смотреть аналитику каждый день и паниковать
→ Данные нужны за 7+ дней. Чаще — шум, не сигнал.

**Ошибка 3:** Изменить текст объявления не меняя campaign_id
→ Потеряешь атрибуцию. Новый текст = новый campaign_id.

**Ошибка 4:** Не проверить что операторы готовы принимать заявки
→ Клиент оставил заявку, никто не взял → потерял деньги и репутацию.
Перед запуском: `/operators` → убедиться что кто-то активен.

**Ошибка 5:** Ждать идеального момента
→ Запускай с тем что есть. Данные важнее перфекционизма.
